GNN：让模型沿着关系学习

一份从直觉、原始论文到可运行实验的学习指南。整理与应用状态核查日期：2026-11-10。适合了解基本神经网络、尚未系统接触图学习的读者。

01 · 为什么需要“图”

把一个人的特征单独交给模型，你能知道年龄、兴趣、消费习惯；把他与朋友、商品、商家的关系也交给模型，你多了一条判断路径：他与谁相连，以及连接对象是什么样的。 图神经网络（Graph Neural Network，GNN）把这种关系变成可学习的计算。

图由节点 V 和边 E 组成。节点可以是用户、原子、路段或设备；边可以是互动、化学键、道路连通或干扰关系。节点特征 X 是一个 N×F 的表：N 个对象，每个有 F 个属性。邻接矩阵 A 是 N×N 的连接表。本教程约定 A[i,j] 表示节点 j 向节点 i 传消息；Demo 为无向图，所以 A 对称。

数据结构 自然邻域 模型如何使用关系
表格 通常没有显式邻域 MLP 分别处理每一行
图像 规则像素网格 CNN 用共享卷积核处理局部窗口
序列 前后顺序或注意力连接 序列模型处理位置与上下文
图 数量不固定、顺序无关的邻居 GNN 沿边传消息并聚合

GNN 的动机不是“关系越多越好”，而是有用的关系可以补充单个对象的信息。如果边由噪声、未来事件或目标标签泄漏构成，图反而可能误导模型。没有可信边时，应先用 MLP、树模型等简单基线。[gcn2017、mpnn2017、gn2018]

02 · 一层 GNN 究竟做了什么

可以把每个节点看作一个有笔记本的人。一次传播包含四件事：邻居把笔记变成消息；节点把收到的消息合成摘要；把摘要与自身状态结合；用所有节点共享的参数更新笔记。堆叠两层，就能间接接触两跳以内的信息。这里的“接触”是计算依赖，并不保证模型能完整保留所有远处信息。

通用消息传递可以写成：

消息：m(j→i) = M(h_i, h_j, e_ij)
聚合：a_i = AGG({m(j→i) : j ∈ N(i)})
更新：h_i' = U(h_i, a_i)

h 是节点当前向量，e 是边特征，M、U 可以是可学习函数。AGG 通常采用求和、均值或最大值，因为邻居交换排列顺序不应改变结果。这叫排列不变聚合。节点重编号后，节点输出应跟着重编号，叫排列等变。图分类再对所有节点读出一个整体向量，通常要求结果对节点编号不变。[mpnn2017、gin2019]

03 · 从直觉走到 GCN 公式

GCN（Graph Convolutional Network）是 GNN 的一种具体形式。Kipf 与 Welling 的常见传播式如下：[gcn2017，式 (2)]

Ã = A + I                  自环：让节点保留自己的消息
D̃_ii = Σ_j Ã_ij            加自环后的节点度数
S = D̃^(-1/2) Ã D̃^(-1/2)   对称归一化的传播矩阵
H^(l+1) = σ(S H^l W^l)      聚合 → 线性变换 → 非线性

I 是单位矩阵；W 是训练得到的共享参数；σ 在隐藏层常用 ReLU，把负值变为零。S 由图决定，W 通过标签监督学习。 不同层的 W 一般不同。对于 F 个输入特征、d 个输出特征，H 为 N×F，W 为 F×d，结果是 N×d。

具体看一条三节点链 A—B—C，加自环后度数是 2、3、2。在一个标量特征上，A 的新状态在变换前为：

z_A = (1/2) x_A + (1/√6) x_B

如果 x_A=1、x_B=2，那么 z_A≈1.3165。注意两个权重相加不等于 1，对称归一化不是普通邻居平均。它同时按发送者和接收者的度数缩放。Demo 的 normalize() 与此一致；测试另用两节点连接加孤立节点验证归一化，自环也让孤立节点避免除零。

两层节点分类器可以写成 logits = S · ReLU(S · X · W0) · W1。logits 是未经 softmax 的分类分数。训练时只取有训练标签的行计算交叉熵；反向传播经过线性层和聚合操作，更新 W0、W1。Demo 使用无偏置 Linear、隐藏层 dropout、Adam 和权重衰减，是教学实现，不是原论文超参数与数据集的完整复现。

04 · 三种任务，三种输出

任务 输入与输出 常见评估与注意点
节点分类 一张图，每个节点预测一个类别 Accuracy、Macro-F1；划分训练/验证/测试节点
边预测 给定两个节点，判断连接概率或关系类型 AUC、AP、排名指标；隔离待预测边与负样本，防止图泄漏
图分类/回归 每张图预测一个性质 分类指标或 MAE/RMSE；对节点作 readout；按整个图划分数据

本 Demo 只实现第一类。分子性质通常属于第三类；推荐常使用节点嵌入与边/排序目标；天气模型常预测节点上的连续物理量。把一张图的节点准确率直接解释成“推荐效果”或“物理仿真精度”没有意义。

另一个重要区别是学习设定。传导式允许训练时看到同一图中测试节点的特征与边，但看不到测试标签；归纳式要求泛化到训练没见过的新节点或新图。GraphSAGE 是理解后一设定的重要入口。本 Demo 是传导式，不能据此宣称能直接泛化到新图。[graphsage2017]

05 · 历史脉络：每篇论文解决了什么

这条时间线是有选择的阅读路线，不是 GNN 的完整起源史。更早的递归神经网络、图核与化学图学习也影响了该领域。年份以主要发表年份为主；预印本可能更早，例如 GCN 为 2016 预印本 / 2017 ICLR，GAT 为 2017 / 2018，GraphCast 为 2022 / 2023。

建议顺序：GCN → MPNN → GraphSAGE → GAT → GIN。再按兴趣分流：推荐看 PinSage/LightGCN，知识图谱看 R-GCN，三维结构看 EGNN，天气看 GraphCast，局部与全局结合看 GraphGPS。读原文时先回答“图如何构建、输入/输出是什么、消息怎样传播、评估怎样划分”，再追细节。

五篇必读，带着问题读

  • GCN：看式 (2) 和实验设定。为什么加入自环？为什么同一个矩阵 S 在每一层出现？哪些节点标签真正进入损失？
  • MPNN：看消息传递阶段与 readout。你能否把某个具体 GNN 写成消息、聚合、更新和读出四步？
  • GraphSAGE：看采样与聚合流程。参数学的是节点 ID，还是一套可复用的邻居聚合函数？新节点还需要哪些特征与邻接信息？
  • GAT：看注意力系数与多头结构。普通局部 GAT 的邻居集合仍由图给定；学权重不意味着自动发现所有缺失边，也不保证权重就是因果解释。
  • GIN：看可区分性与聚合器条件。求均值可能混淆什么不同邻居集合？论文的表达力结论依赖假设，不能扩展成“所有图都可区分”。

06 · 应用情况：部署证据与研究价值分开看

以下是截至核查日可溯源的代表案例，不是市场份额统计或全行业清单。历史部署证明了可行性，不自动证明 2026 年仍运行同一版本。逐条核验记录与限制见 应用事实核查。

领域 如何建图、预测什么 证据层级与适用边界
推荐与内容检索 用户/物品/收藏板为节点，交互为边，学习物品嵌入用于召回或排序 PinSage 2018 论文报告 Pinterest 生产部署；MultiBiSage 2022 报告多关系图研究。未核实 2026 线上架构；不能把后者离线结果说成全面上线
交通与 ETA 路段及连接关系形成图，结合时空特征预测行程时间 Google/DeepMind 2020 官方材料有产品部署证据；属于历史验证，当前具体模型架构待确认
天气预测 大气状态放在网格与多尺度网格图上，预测下一时刻状态并滚动推进 GraphCast 2023 是重要科研里程碑；Google 当前文档写 WeatherNext Graph 已弃用，ECMWF 新公告也停止对应外部模型实时运行。代码/模型研究价值与当前服务状态须分开
材料发现 原子与近邻关系形成晶体图，预测候选性质，配合 DFT 再验证 GNoME 2023 论文与 Materials Project 数据库版本记录支持科研及数据资产用途；计算稳定不等于一定可合成，更不等于已量产
分子性质与几何学习 原子、键、空间距离；预测能量、性质或坐标更新 MPNN、EGNN 是方法与基准验证证据；不能把基准效果直接写成药物获批或临床收益
知识图谱 实体为节点，多种关系为有类型的边 R-GCN 支持实体分类、链路预测研究；图数据库、GraphRAG 本身不必然使用 GNN

无线、反欺诈、电网等也有自然的图建模问题，但此包不据此宣称已具备本部门落地效果。若迁移到通信：先定义节点是用户/小区/天线中的哪一种，边是连接还是干扰，标签来自仿真还是测量，推理时能看到哪些信息；再与传统算法比较时延、算力、约束满足率和分布外表现。这里是教学类比，不是 AI-RAN 业务线的事实或收益结论。

07 · 哪些问题仍然难

相连不等于相似。 社交朋友可能相似，交易双方或不同类型设备却可能天然不同。邻居类别相似叫同配，反之叫异配。直接平均在异配图上可能破坏有用信号。用 Demo 把 --p-in 降到接近 --p-out，观察优势是否消失。[heterophily2020]

更深不保证更强。 反复传播可能让节点表示越来越难区分，称为过平滑。在对称归一化下，极限还与节点度有关，并不一定是所有原始数值完全相等。另一个问题是过挤压：大量远处的信息经少量路径被挤进固定长度向量。两者不是同一问题；单纯加层并不能解决。[oversmoothing2018、bottleneck2021]

图也会过时或泄漏答案。 随机划分能回答“同图中缺少标签的节点能否补全”，却不等于能预测未来。真实业务应考虑时间划分、重复实体、未来边、训练后才出现的特征，以及训练与线上建图规则一致性。

计算受图结构限制。 教学代码使用稠密 N×N 矩阵，存储约为 O(N²)，是为了让公式清楚。真实大图需要稀疏矩阵、邻居采样、mini-batch 与离线嵌入刷新等工程手段。GraphSAGE 和 PinSage 值得在这一步读。GAT 的自适应权重、几何等变网络的空间约束、GraphGPS 的全局注意力都是不同的设计选择，不是一条“新模型全面替代旧模型”的线性路线。

08 · 自己训练：观察关系的作用

数据完全由本地随机数生成，无需账号、数据集下载或 GPU。图包含 3 个社区、每类 60 个节点，共 180 个节点，每节点 16 维特征。默认社区内连接概率 0.18，社区间 0.015，特征含高斯噪声。类别参与合成特征与图结构的生成，制造可控制的学习问题；真实业务不能使用未知目标标签建图。

每类训练/验证/测试节点为 8/12/40，因此总计 24/36/120。特征标准化只拟合训练节点。训练时允许看到全图特征与边；只有训练标签进入梯度。验证标签用于选取最小验证损失的 checkpoint；测试指标在该 checkpoint 选好后计算一次。三个随机种子同时改变数据、划分与初始化，所以这里的标准差混合了三种随机性，不是单纯优化器不确定性。

实验 传播操作 你在检验什么
GCN 使用真实图的 S 有效邻域能否帮助消除特征噪声
MLP 使用单位矩阵 I 不看边，仅凭本节点属性能做到什么程度
No edges 删掉所有邻居边，只保留自环 在本实现中应与 MLP 完全一致，是实现一致性检查
Shuffled 对 A 的行列作同一随机置换，X 与标签不变 保留边数、图拓扑与度分布，破坏图和节点属性/类别的对应关系；不保证逐节点度数保持

这里 MLP 与 GCN 使用相同宽度、层数、无偏置线性层、dropout、优化器和初始化种子；MLP 通过传播矩阵 I 实现。No edges 与 MLP 不是两项独立方法，它们相等正是预期行为。该对照说明特定构造的数据依赖哪些信息，不构成真实基准排名。

反例也跑一遍：边没有社区线索时

已用相同三个种子实际运行 p_in=p_out=0.06。GCN 测试准确率均值为 40.8%（样本标准差 4.6 个百分点），MLP 为 49.7%。图结构不再提供类别聚集线索时，聚合可能混入无关邻居，GCN 的优势消失。这比只看默认图上的 100% 更能说明方法的适用边界。

负对照完整结果与实验图一并保留；不同条件都没有用测试集选 checkpoint，但这些固定合成实验仍不构成真实业务结论。

uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r demo/requirements.txt

评估已保存权重（仅加载自己生成或可信的 checkpoint）：

.venv/bin/python demo/train.py \
  --evaluate outputs/gcn-7.pt --out outputs/re-evaluation

四个有解释力的练习

  1. 边不再提供类别线索：--p-in 0.06 --p-out 0.06 --out outputs/no-community。不要预设 GCN 一定胜过 MLP；关注多种子均值与波动。
  2. 增加特征噪声：--noise 2.5 --out outputs/noisy。图仍可靠时，比较邻居聚合的价值。
  3. 增加深度：--layers 8 --out outputs/deep。本模型无残差，深度可能增加平滑与优化困难；不能只凭准确率下降就断言唯一原因是过平滑。
  4. 去掉 dropout：--dropout 0 --out outputs/no-dropout。比较训练与验证曲线，讨论过拟合。

上面命令的参数需接在 .../demo/train.py 后；输出路径分别保留，避免覆盖默认参考结果。也可用 --seeds 7 17 27 37 47 扩大实验。更严格的后续实验应固定数据与划分，只改变模型初始化；再换新图评估归纳能力。学习包没有宣称完成 Cora 等真实数据集复现。

  • demo/train.py：make_graph() 构造数据与划分；normalize() 实现 S；Network.forward() 对应公式；fit() 分开训练损失、验证选模与测试评估。
  • demo/test_train.py：覆盖手算归一化、孤立节点、节点排列等变、数据划分、标签隔离、退化到 MLP、训练与 checkpoint 重载，以及非法输入。
  • outputs/：每个模型/种子的 .pt 权重、逐 epoch CSV、results.json 指标与混淆矩阵、experiment.png/.svg 图。best_epoch 可以定位实际使用的轮次。
  • source/manifest.json：原始文件来源、实际下载 URL、时间、字节数、SHA-256、PDF 页数、版本标记与首页文本。它证明下载内容可追踪，SHA-256 本身不是作者身份认证。
